A LITTLE GUIDANCE

The language of patterns

Use capital letters for subpatterns and lowercase text for literal sounds. Spaces outside quotes are ignored.

a/b
Choose one option. Add a weight, as in a/b*3.
[a/b]
Group options; (a/b) makes the group optional.
"text"
Write special characters or capitals literally.
[VV]^aa
Discard a generated word when the preceding fragment matches the filter.

Each attempt can be filtered out, so the output may contain fewer words than requested. Read the original Awkwords help ↗

ABOUT KOTHAR

Made for makers

Kothar takes its name from Kothar-wa-Khasis (Ugaritic: 𐎋𐎘𐎗𐎆𐎃𐎒𐎒; Kôṯaru-wa-Ḫasisu), an Ugaritic divine artisan associated with architecture, smithing, music, and magic. Some scholars consider the name to represent two gods, Kothar and Khasis, combined into one.

Kothar is a distinct, browser-based implementation inspired by Awkwords 1.2, created by Petr Mejzlík. It is not the original Awkwords.
